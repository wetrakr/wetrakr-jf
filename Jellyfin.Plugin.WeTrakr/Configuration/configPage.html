WeTrakr

Automatically send playback events to your WeTrakr profile. Movies and episodes are tracked: pause, resume and stop are detected from the player. Every Jellyfin account can be connected to its own WeTrakr account; accounts left unconnected are never sent anywhere.

Each account confirms the code with their own WeTrakr login, so you never see their credentials.

This server is still using the old single-account pairing (connected as -): playback from every Jellyfin account is sent to that WeTrakr profile, which then filters it. Connect the accounts below to give each person their own profile, or drop it to stop scrobbling entirely.
